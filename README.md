# Trekko Store

Este repositório contém os arquivos estáticos e a documentação do projeto **Trekko Store**, um e-commerce focado em esportes outdoor com pets. A aplicação foi desenvolvida com React e Vite, e a pasta `dist` já possui a build otimizada.

## Visualização rápida

1. Extraia o conteúdo de `dist.zip`:
   ```bash
   unzip dist.zip
   ```
2. Abra `dist/index.html` em seu navegador para visualizar o site.

## Documentação

Diversos guias estão disponíveis para auxiliar no deploy e na manutenção do projeto:

- `GUIA_DEPLOY.md` – passo a passo para hospedar os arquivos em um servidor.
- `GUIA_GITHUB_PAGES.md` e `GUIA_GITHUB_PAGES_WINDOWS.md` – instruções para publicar no GitHub Pages.
- `DOCUMENTACAO_COMPLETA.md` – visão geral de todas as páginas e recursos.

Sinta-se à vontade para explorar os demais arquivos para conhecer mais detalhes sobre o Trekko Store.
